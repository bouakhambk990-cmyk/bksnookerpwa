# ຕູ້ຄິດໄລ່ຫວຍ (Lao Lottery Calculator)

ເຄື່ອງມືຄິດໄລ່ຍອດແທງຫວຍ — ພິມຊຸດເລກ + ລາຄາຕາມຮູບແບບປົກກະຕິ ລະບົບຈະແຍກເລກ ຄິດເງິນ ຫັກເລກຫ້າມ ແລະ ສະຫລຸບຍອດລວມ / ຍອດສົ່ງ / ຍອດຮັບ / % ທີ່ໄດ້ ໃຫ້ອັດຕະໂນມັດ.

ເປັນເວັບໜ້າດຽວ (`index.html`) ໃຊ້ HTML + JavaScript ລ້ວນໆ — **ບໍ່ຕ້ອງຕິດຕັ້ງຫຍັງ, ບໍ່ຕ້ອງມີ server ຂອງຕົນເອງ**. ຄິດໄລ່ຫຼັກເຮັດຢູ່ໃນເຄື່ອງ/browser ຂອງຜູ້ໃຊ້ 100% ແລະ ຈະບໍ່ສົ່ງຂໍ້ມູນອອກໄປໃສເລີຍ **ເວັ້ນເສຍແຕ່ທ່ານຈະເປີດໃຊ້ຄຸນສົມບັດຜູ້ໃຊ້ + Google Sheet ແບບບໍ່ບັງຄັບ (ຂໍ້ 7)**.

---

## 1. ວິທີໃຊ້ແບບໄວທີ່ສຸດ (ບໍ່ຕ້ອງອັບ GitHub)

ດາວໂຫລດ (ຫຼືໂຄລນ repo) ແລ້ວດັບເບີ້ນຄລິກໄຟລ໌ `index.html` — ມັນຈະເປີດຢູ່ໃນ browser ທັນທີ ໃຊ້ໄດ້ເລີຍ.

---

## 2. ວິທີອັບໂຫລດຂຶ້ນ GitHub

### ຕົວເລືອກ A — ອັບຜ່ານໜ້າເວັບ GitHub (ບໍ່ຕ້ອງໃຊ້ command line, ງ່າຍສຸດ)

1. ເຂົ້າ https://github.com ແລ້ວ login (ຫຼືສະໝັກບັນຊີໃໝ່ຖ້າຍັງບໍ່ມີ)
2. ກົດ **New repository** (ປຸ່ມ `+` ມຸມຂວາເທິງ → New repository)
3. ຕັ້ງຊື່ repo ເຊັ່ນ `lao-lottery-calculator` → ເລືອກ **Public** → ກົດ **Create repository**
4. ໃນໜ້າ repo ໃໝ່ ກົດ **uploading an existing file** (ຫຼື drag ໄຟລ໌ເຂົ້າໄປໃນໜ້າໂດຍກົງ)
5. ລາກໄຟລ໌ `index.html` ແລະ `README.md` ເຂົ້າໄປໃນຊ່ອງອັບໂຫລດ
6. ເລື່ອນລົງລຸ່ມ ພິມຂໍ້ຄວາມ commit ເຊັ່ນ `"Add calculator"` → ກົດ **Commit changes**

ແລ້ວແຕ່ນີ້ໄຟລ໌ຈະຢູ່ໃນ repo ຂອງທ່ານແລ້ວ.

### ຕົວເລືອກ B — ອັບຜ່ານ Git command line

ຕ້ອງມີ [Git](https://git-scm.com/downloads) ຕິດຕັ້ງໃນເຄື່ອງກ່ອນ. ເປີດ Terminal / Command Prompt ໃນໂຟນເດີທີ່ມີໄຟລ໌ `index.html` ແລະ `README.md` ແລ້ວພິມ:

```bash
git init
git add .
git commit -m "Add Lao lottery calculator"
git branch -M main
git remote add origin https://github.com/<ຊື່ຜູ້ໃຊ້ຂອງທ່ານ>/lao-lottery-calculator.git
git push -u origin main
```

> ປ່ຽນ `<ຊື່ຜູ້ໃຊ້ຂອງທ່ານ>` ໃຫ້ເປັນ GitHub username ຈິງຂອງທ່ານ, ແລະ ຕ້ອງສ້າງ repo ຊື່ `lao-lottery-calculator` ຢູ່ GitHub ກ່ອນ (ຄືຂັ້ນຕອນ 1-3 ຂອງຕົວເລືອກ A) ຫຼືປ່ຽນຊື່ໃນຄຳສັ່ງໃຫ້ກົງກັບ repo ຂອງທ່ານ.

## 3. ວິທີເປີດໃຊ້ຜ່ານລິ້ງອອນລາຍ (GitHub Pages — ຟຣີ)

ຫຼັງຈາກອັບໄຟລ໌ຂຶ້ນ GitHub ແລ້ວ, ສາມາດເປີດເປັນເວັບໄຊທ໌ຈິງ (ມີລິ້ງໃຫ້ຄົນອື່ນເປີດໄດ້) ໂດຍ:

1. ໄປທີ່ repo ຂອງທ່ານໃນ GitHub → ກົດແຖບ **Settings**
2. ເລືອກເມນູ **Pages** (ຢູ່ແຖບຊ້າຍ)
3. ໃນຫົວຂໍ້ **Build and deployment → Source** ເລືອກ **Deploy from a branch**
4. ໃນ **Branch** ເລືອກ `main` ແລະ ໂຟນເດີ `/ (root)` → ກົດ **Save**
5. ລໍປະມານ 1-2 ນາທີ ແລ້ວ refresh ໜ້າ Settings → Pages ອີກຄັ້ງ ຈະເຫັນລິ້ງເວັບໄຊທ໌ຂອງທ່ານ ຮູບແບບ:

```
https://<ຊື່ຜູ້ໃຊ້ຂອງທ່ານ>.github.io/lao-lottery-calculator/
```

ເປີດລິ້ງນີ້ຈາກໂທລະສັບ ຫຼືຄອມພິວເຕີໃດກໍ່ໄດ້ ໃຊ້ງານໄດ້ທັນທີ ບໍ່ຕ້ອງດາວໂຫລດຫຍັງອີກ.

## 4. ຮູບແບບການພິມຂໍ້ມູນ (syntax)

| ຮູບແບບ | ຄວາມໝາຍ |
|---|---|
| `11,51,91= 20` | ຊຸດເລກ 11 51 91 ລາຄາ 20,000 (ຄັ່ນເລກດ້ວຍ `, . - ; /` ຫຼືວັກ) |
| `: = ຮູ ຮູ້ ຮູລະ` | ເຄື່ອງໝາຍຄັ່ນລາຄາ (ໃຊ້ອັນໃດກໍ່ໄດ້) |
| `: 5` | ລາຄາເປົ່າໆ = ພັນ → 5,000 |
| `= 1ລ້ານ` | 1,000,000 |
| `: 2ແສນ` | 200,000 |
| `=200฿` ຫຼື `=200ບາດ` | ນັບເປັນມູນຄ່າຈິງ (200) ບໍ່ຄູນພັນ |
| `20*10` | ແຍກ 2 ລາຄາໃນຊຸດດຽວ (ລວມ 2 ລາຄາເຂົ້າກັນ) |
| `ບລ` / `ບົນ-ລ່າງ` | ໃສ່ໃນແຖວ ຫຼືແຖວແຍກຕໍ່ທ້າຍ → ຄູນ 2 ສະເພາະຊຸດເລກ 2 ໂຕ |
| ຫຼາຍແຖວເລກ ຕິດກັນ ແລ້ວປິດທ້າຍດ້ວຍແຖວລາຄາຢ່າງດຽວ | ລາຄານັ້ນນຳໃຊ້ກັບທຸກແຖວເລກຂ້າງເທິງ |
| `ຫລັກ 8 7 3 = 10` | ຕໍ່ຈາກແຖວຊຸດເລກ 2 ໂຕ → ສ້າງເລກ 3 ໂຕໃໝ່ (ໂຕນຳໜ້າ + ຊຸດເລກ 2 ໂຕເທິງ) ໃນລາຄາໃໝ່ |

ຊ່ອງ **ເລກທີ່ຕ້ອງຫ້າມ** ໃຊ້ຮູບແບບຄັ່ນດຽວກັນ, ເລກທີ່ຕົງກັນຈະຖືກຕັດອອກຈາກຍອດລວມໂດຍອັດຕະໂນມັດ.

### ປຸ່ມ ລ້າງຂໍ້ມູນ
ຢູ່ຕິດມຸມຂວາຂອງຊ່ອງ "ລາຍການເລກ + ລາຄາ" — ກົດເທື່ອທຳອິດປຸ່ມຈະປ່ຽນເປັນສີແດງ "ກົດອີກຄັ້ງເພື່ອລ້າງ", ກົດເທື່ອສອງພາຍໃນ 3 ວິນາທີຈຶ່ງລ້າງແທ້ (ປ້ອງກັນລ້າງຜິດ).

## 6. ໝາຍເຫດ

- ຂໍ້ມູນຄິດໄລ່ຫຼັກຄິດຢູ່ໃນ browser ຂອງຜູ້ໃຊ້. ຂໍ້ມູນຈະຖືກສົ່ງອອກໄປພາຍນອກ ກໍ່ຕໍ່ເມື່ອທ່ານເປີດໃຊ້ຄຸນສົມບັດ Google Sheet ໃນຂໍ້ 7 ເທົ່ານັ້ນ.
- ຖ້າແຖວໃດພິມຜິດຮູບແບບ ລະບົບຈະຂຶ້ນຄຳເຕືອນສີແດງບອກເລກແຖວທີ່ອ່ານບໍ່ອອກ ໂດຍບໍ່ຢຸດການຄິດໄລ່ແຖວອື່ນ

## 7. ເຊື່ອມຕໍ່ Google Sheet + ຜູ້ໃຊ້ (ບໍ່ບັງຄັບ)

ຄຸນສົມບັດນີ້ໃຫ້ທ່ານ:
- ຕັ້ງ **ຜູ້ໃຊ້** ຫຼາຍຄົນ, ແຕ່ລະຄົນມີ/ບໍ່ມີ **ວັນໝົດອາຍຸ** (ໝົດແລ້ວເຂົ້າໃຊ້ບໍ່ໄດ້)
- ພິມລາຍການເລກ+ລາຄາ ແລ້ວກົດປຸ່ມ/enter ເພື່ອ **ສົ່ງເຂົ້າ Google Sheet ຂອງທ່ານທັນທີ** — ຊີດຄິດໄລ່ຍອດຕໍ່ເອງຕາມສູດທີ່ທ່ານມີຢູ່ແລ້ວ (ຄືຕົວຢ່າງໃນຮູບ)

**ຂໍ້ຄວນຮູ້ກ່ອນເລີ່ມ (ສຳຄັນ):** ໜ້າເວັບນີ້ເປັນ static site ບໍ່ມີ server ຂອງຕົນເອງ. ເພື່ອໃຫ້ມັນຂຽນລົງ Google Sheet ໄດ້ ຕ້ອງໃຊ້ **Google Apps Script** ເປັນ "ຝາຫລັງ" (backend) ຟຣີທີ່ຜູກກັບ Sheet ຂອງທ່ານເອງ. ນີ້ແມ່ນວິທີມາດຕະຖານທີ່ໃຊ້ກັນທົ່ວໄປສຳລັບ static site ທີ່ຢາກຂຽນລົງ Sheet.

⚠️ **ຂໍ້ຈຳກັດເລື່ອງຄວາມປອດໄພ:** ນີ້ເປັນລະບົບປ້ອງກັນລະດັບ "ສະດວກໃຊ້ງານ" ສຳລັບກຸ່ມຄົນທີ່ໄວ້ໃຈກັນ (ເຊັ່ນ agent ຂອງທ່ານ) — ບໍ່ແມ່ນຄວາມປອດໄພລະດັບທະນາຄານ. ເນື່ອງຈາກ `index.html` ເປັນໄຟລ໌ສາທາລະນະ (public) ໃຜກໍ່ເບິ່ງ source code ໄດ້ ຮວມທັງ TOKEN ທີ່ຝັງໄວ້ໃນນັ້ນ. ຢ່າໃຊ້ລະຫັດ/token ດຽວກັນກັບບັນຊີສຳຄັນອື່ນ, ແລະ ໃຫ້ຖືວ່າໃຜກໍ່ອາດເບິ່ງເຫັນ token ນີ້ໄດ້ຖ້າພະຍາຍາມຫຼາຍພໍ.

### 7.1 ສ້າງໂຄງສ້າງ Sheet

1. ໃນ Google Sheet ຂອງທ່ານ (ຄືໃນຮູບຕົວຢ່າງ) ໃຫ້ຈື່ຊື່ແຖບ (tab) ທີ່ຈະຂຽນຂໍ້ມູນໃສ່ — ໃນຕົວຢ່າງແມ່ນ `No1.`
2. ຈື່ໄວ້ວ່າຄໍລໍາໃດແມ່ນ ລำດັບ / ເລກ / ລາຄາ, ແລະ ແຖວໃດແມ່ນແຖວທຳອິດຂອງລາຍການ (ໃນຮູບຄື ແຖວ 18) — ຈະໃຊ້ຕັ້ງຄ່າໃນຂໍ້ 7.4

### 7.2 ສ້າງ Google Apps Script

1. ເປີດ Google Sheet ຂອງທ່ານ → ເມນູ **Extensions → Apps Script**
2. ລຶບໂຄ້ດຕົວຢ່າງໃນ `Code.gs` ອອກໝົດ ແລ້ວແປະໂຄ້ດຈາກໄຟລ໌ `Code.gs` ທີ່ໃຫ້ມາໃນແພັກເກັດນີ້ລົງແທນ
3. ໃນແຖວທຳອິດຂອງໂຄ້ດ ຊອກຫາ:
   ```js
   var TOKEN = 'CHANGE_THIS_SECRET_TOKEN';
   ```
   ປ່ຽນ `CHANGE_THIS_SECRET_TOKEN` ເປັນລະຫັດລັບຂອງທ່ານເອງ (ພິມຫຍັງກໍ່ໄດ້ ຍາວໆ ຄາດເດົາຍາກ)
4. ກົດ **Save** (ຮູບແຜ່ນດິສ)

### 7.3 ເຜີຍແຜ່ (Deploy) ເປັນ Web App

1. ກົດ **Deploy → New deployment**
2. ກົດຮູບເຟືອງ ⚙️ ຂ້າງ "Select type" → ເລືອກ **Web app**
3. ຕັ້ງຄ່າ:
   - **Execute as:** `Me` (ບັນຊີ Google ຂອງທ່ານ)
   - **Who has access:** `Anyone`
4. ກົດ **Deploy** → ອະນຸຍາດສິດ (Authorize access) ຕາມທີ່ Google ຖາມ (ເລືອກບັນຊີ, ກົດ Advanced → Go to [ຊື່ໂປຣເຈັກ] (unsafe) ຖ້າມີຄຳເຕືອນ — ປົກກະຕິເພາະສະຄຣິບເປັນຂອງທ່ານເອງ)
5. ຫຼັງ Deploy ສຳເລັດ ຈະໄດ້ **Web app URL** ໜ້າຕາຄ້າຍ:
   ```
   https://script.google.com/macros/s/xxxxxxxxxxxxxxxxxxxxx/exec
   ```
   **ກັອບປີ້ URL ນີ້ໄວ້** ຈະໃຊ້ໃນຂັ້ນຕອນຕໍ່ໄປ

> ຖ້າຫຼັງແກ້ໂຄ້ດໃນ Apps Script ອີກ ຕ້ອງກົດ **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** ຄືນທຸກຄັ້ງ ບໍ່ດັ່ງນັ້ນການແກ້ໄຂຈະບໍ່ມີຜົນ

### 7.4 ຕັ້ງຄ່າໃນ index.html

ເປີດໄຟລ໌ `index.html` ດ້ວຍໂປຣແກຣມແກ້ໄຂຂໍ້ຄວາມ (Notepad, VS Code, ...) ຄົ້ນຫາຄຳວ່າ `CONFIG` (ຢູ່ໃກ້ຕົ້ນ `<script>`) ຈະເຫັນ:

```js
var CONFIG = {
  WEBAPP_URL: 'PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE',
  SHARED_TOKEN: 'CHANGE_THIS_SECRET_TOKEN',
  ADMIN_PASSWORD: 'CHANGE_THIS_ADMIN_PASSWORD',
  SHEET_TAB: 'No1.',
  START_ROW: 18,
  COL_INDEX: 'B',
  COL_NUMBER: 'C',
  COL_PRICE: 'D'
};
```

ແກ້ໄຂແຕ່ລະຄ່າ:

| ຄ່າ | ໃສ່ຫຍັງ |
|---|---|
| `WEBAPP_URL` | URL ທີ່ໄດ້ຈາກຂໍ້ 7.3 |
| `SHARED_TOKEN` | ຄືກັນເປ๊ະກັບ `TOKEN` ທີ່ຕັ້ງໃນ `Code.gs` ຂໍ້ 7.2 |
| `ADMIN_PASSWORD` | ລະຫັດສຳລັບເປີດແຜງ "ຈັດການຜູ້ໃຊ້" — ຕັ້ງເອງ |
| `SHEET_TAB` | ຊື່ແຖບ (tab) ໃນ Sheet ທີ່ຈະຂຽນລົງ (ຄືຂໍ້ 7.1) |
| `START_ROW` | ແຖວທຳອິດຂອງລາຍການ (ໃນຮູບຕົວຢ່າງ = `18`) |
| `COL_INDEX` | ຕົວອັກສອນຄໍລໍາ ລำດັບ (ໃນຮູບຕົວຢ່າງ = `B`) |
| `COL_NUMBER` | ຕົວອັກສອນຄໍລໍາເລກ/ຢ່ອຍ (ໃນຮູບຕົວຢ່າງ = `C`) |
| `COL_PRICE` | ຕົວອັກສອນຄໍລໍາລາຄາ (ປັບໃຫ້ກົງກັບ Sheet ຈິງຂອງທ່ານ — ບາງຄໍລໍາອາດຖືກເຊື່ອງໄວ້ຢູ່) |

ບັນທຶກໄຟລ໌ ແລ້ວອັບ (ຫຼືອັບເດດ) ຂຶ້ນ GitHub ຄືເດີມ (ຂໍ້ 2).

ເມື່ອຕັ້ງຄ່າຄົບແລ້ວ ໜ້າເວັບຈະ **ອັດຕະໂນມັດເປີດການລ໋ອກອິນ + ແຜງ Admin + ຊ່ອງສົ່ງເຂົ້າ Sheet ໃຫ້ເອງ**. ຖ້າຍັງບໍ່ໄດ້ຕັ້ງຄ່າ (ຍັງເປັນຄ່າ `PASTE_YOUR_...`) ໜ້າເວັບຈະເຮັດວຽກແບບເດີມທັງໝົດ ບໍ່ຮ້ອງຂໍລ໋ອກອິນ.

### 7.5 ວິທີເພີ່ມຜູ້ໃຊ້

1. ເປີດເວັບ (ຫຼັງຕັ້ງຄ່າແລ້ວ) → ຈະຂຶ້ນໜ້າລ໋ອກອິນ
2. ລ໋ອກອິນຄັ້ງທຳອິດຈະບໍ່ມີຜູ້ໃຊ້ໃດເລີຍ (ຍັງເພີ່ມບໍ່ໄດ້) — ໃຫ້ໄປທີ່ Google Sheet ຂອງທ່ານໂດຍກົງ, ເປີດແຖບ **Users** (ຈະຖືກສ້າງອັດຕະໂນມັດຄັ້ງທຳອິດທີ່ມີການເອີ້ນໃຊ້) ແລ້ວພິມຊື່ຜູ້ໃຊ້ທຳອິດເອງໃສ່ຄໍລໍາ Username ດ້ວຍມື (ຄໍລໍາ ExpiryISO ປະໄວ້ຫວ່າງ = ບໍ່ໝົດເວລາ)
3. ໃຊ້ຊື່ນັ້ນລ໋ອກອິນຄັ້ງທຳອິດ → ກົດ "ຈັດການຜູ້ໃຊ້ (Admin)" ຢູ່ໜ້າຫຼັກ → ພິມລະຫັດ Admin (ຄ່າ `ADMIN_PASSWORD` ໃນຂໍ້ 7.4) → ຫຼັງຈາກນັ້ນສາມາດ **ເພີ່ມຜູ້ໃຊ້ໃໝ່ + ຕັ້ງວັນໝົດອາຍຸ** ຜ່ານໜ້າເວັບໄດ້ເລີຍ ບໍ່ຕ້ອງເຂົ້າ Sheet ອີກ
4. ວັນໝົດອາຍຸ (ຖ້າຕັ້ງ) — ຫຼັງເວລານັ້ນຜ່ານໄປ ຜູ້ໃຊ້ຄົນນັ້ນຈະລ໋ອກອິນບໍ່ໄດ້ອີກ (ຂຶ້ນ "ໝົດເວລາໃຊ້ງານ")

### 7.6 ວິທີສົ່ງລາຍການເຂົ້າ Sheet

ຫຼັງລ໋ອກອິນແລ້ວ ຈະເຫັນຊ່ອງ "ສົ່ງເຂົ້າ Google Sheet" ຢູ່ລຸ່ມສຸດຂອງໜ້າ — ພິມ 1 ລາຍການ (ຮູບແບບດຽວກັນກັບຊ່ອງຫຼັກ ເຊັ່ນ `11,51,91=20`) ແລ້ວກົດ **Enter** ຫຼືປຸ່ມ **ສົ່ງເຂົ້າຊີດ** — ແຕ່ລະເລກຈະຖືກຂຽນເປັນແຖວໃໝ່ຕໍ່ທ້າຍລາຍການເກົ່າໃນ Sheet ໂດຍອັດຕະໂນມັດ, ສູດຄິດໄລ່ທີ່ທ່ານມີຢູ່ແລ້ວໃນ Sheet ຈະຄິດຍອດລວມໃຫ້ເອງທັນທີ.
